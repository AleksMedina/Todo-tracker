## Основной функционал
* **Интерфейс:** поле ввода, делайдлайн (дата и время), приоритет, цвет, кнопка «Добавить», чекбоксы, удаление задачи.
* **Блоки:** «Горит», «Высокий приоритет», «Остальные», «Выполнено». Пустые блоки скрываются.
* **Автосортировка:** срочное и важное поднимается наверх по правилам:
  1. просроченные (делайлайн уже прошёл);
  2. до дедлайна меньше 24 часов;
  3. все остальные.
* **Чекбоксы:** красная рамка и зелёная галочка; цвет меняется для каждой задачи и по умолчанию.
* **Health check:** `GET /health` проверяет, что SQLite читается и каталог с БД доступен для записи (возвращает `200` или `503`).
* **Метрики использования:** `todo_tasks_added_total`, `todo_tasks_completed_total`, `todo_page_visits_total` (в Grafana отображаются через `increase(...[1h])`).
* **Ресурсы мониторинга:** контейнер приложения (`cAdvisor`) и сервер (`node-exporter`).

## Блоки, приоритеты и сортировка

Задача имеет приоритет (высокий, средний, низкий) и необязательный дедлайн. Сервер отдаёт список уже отсортированным (`GET /api/tasks`), страница обновляет его каждые 30 секунд, поэтому задачи сами «поднимаются» по мере приближения срока.

| Блок | Что попадает |
| :--- | :--- |
| **Горит** | просроченные и со сроком меньше суток |
| **Высокий приоритет** | остальные задачи с высоким приоритетом |
| **Остальные** | средний и низкий приоритет |
| **Выполнено** | отмеченные чекбоксом |

## API приложения

| Метод и путь | Назначение |
| :--- | :--- |
| `GET /api/tasks` | список в порядке сортировки (поля `status`: `overdue`, `soon`, `normal`, `done`) |
| `POST /api/tasks` | добавление (`title`, `priority`: 1..3, `deadline`: ISO 8601, `color`: "#rrggbb") |
| `PATCH /api/tasks/{id}` | обновление полей (`done`, `priority`, `deadline`, `color`) |
| `POST /api/tasks/reset-colors` | сбросить цвета у всех задач |
